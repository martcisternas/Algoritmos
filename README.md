# Algoritmos en Python

Repositorio de ejercicios y actividades desarrollados durante mi formación como Analista Programador en Duoc UC.

## 📚 Contenidos

Este repositorio reúne ejercicios prácticos orientados al desarrollo de lógica de programación y resolución de problemas mediante Python.

### Ejercicios incluidos

- 🏨 Sistema de gestión de habitaciones de un hotel
- 🏭 Sistema de gestión de espacios de un almacén
- 💰 Sistema básico de gestión de gastos

## 🛠️ Tecnologías

- Python 3

## 🎯 Objetivo

Practicar conceptos fundamentales de programación, incluyendo:

- Variables y tipos de datos
- Condicionales
- Ciclos `while`
- Validación de datos
- Contadores y acumuladores
- Entrada y salida de información
- Resolución de problemas mediante algoritmos
